## Локальный запуск

На Android в Termux при наличии Python:
```sh
cd CURRENT_GAME_V0_6/dist
python -m http.server 8080 --bind 127.0.0.1
```
Открыть http://127.0.0.1:8080. Не открывать index.html через file://: используются ES-модули.

Проверки из CURRENT_GAME_V0_6, нужен Node.js:
```sh
node checks/engine.test.mjs
node checks/scene.test.mjs
node checks/combat.test.mjs
node checks/garages.test.mjs
node checks/ui.test.mjs
```
В Termux можно ограничивать каждый запуск `timeout 30s node ...`.

## Проверено и не проверено

Эти проверки проходили при выпуске 0.6: маршруты, коллизии, добыча без дублирования, миграция сохранения, проход туда-обратно в правый кабинет, 32 выстрела и четыре перезарядки с бесконечным запасом, ближний бой, поиск пути заражённого, независимые два стика, выбор двух локаций с общим рюкзаком.
UI-тест — имитация DOM/Canvas; это не браузерный или Android-прогон. Игровая отрисовка проверялась отдельными native Canvas-кадрами. Плавность, звук и точность касаний на реальном телефоне не подтверждены. Отдельные картинки не являются доказательством готовой игровой карты.

## Вспомогательные рендер-скрипты
QA/RENDER_SCRIPTS — исходные одноразовые проверки из среды разработки. В них остались абсолютные пути /workspace/... и путь к установленной там native Canvas-библиотеке. Это материалы для понимания проверки, не переносимый способ запуска игры. Сам игровой исходник и пять checks/*.mjs используют относительные импорты и запускаются независимо от этих скриптов.
