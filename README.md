# DEAD SIGNAL — Первый сигнал

Первый играбельный прототип 0.1. Самостоятельный веб-клиент, без Telegram SDK, аккаунтов и сервера.

Проход: убежище → гаражи → обыск гаража № 28 → аккумулятор → выход слева → свет в убежище.

На телефоне: удерживать стрелки, нажимать кнопку действия рядом с предметами. На клавиатуре: A/D или стрелки, E для действия, Escape для паузы. Дополнительные ящики содержат бинт и металлолом. Звук включается отдельной кнопкой и пока ограничен простыми синтезированными эффектами.

Сохранение: localStorage `dead-signal-save-v1`, только после возвращения; кнопка «Начать заново» очищает его. Это локальное сохранение конкретного браузера, без синхронизации и защиты от изменения.

`dist/engine.mjs` — правила игры без зависимости от DOM; `dist/game.js` — Canvas, ввод, экранные состояния и сохранение. `dist/assets/` — сжатые концепты для экранов убежища. Игровая локация и герой рисуются программно; это базовая графика прототипа, не финальные спрайты из концептов.

Проверено: синтаксис JS; сбор аккумулятора, запрет повторной добычи, условие возвращения, границы локации, валидация сохранения; полный проход интерфейса с имитацией DOM/Canvas и мобильного размера. Визуальная проверка в настоящем браузере и на Android не выполнена.

Следующий ограниченный этап: проверка на Android, затем один заражённый и простой бой. Не расширять карту до завершения этих шагов.
