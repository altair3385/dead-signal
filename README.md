# DEAD SIGNAL — Первый сигнал · 0.2

Играбельная веб-сцена с ортографической камерой сверху. Обновляет прежний прототип с видом сбоку. Не подключена к Telegram SDK и серверу; без боя и мультиплеера.

## Проход

1. «Новая игра». На телефоне удерживать джойстик, на клавиатуре — WASD/стрелки.
2. У главного входа нажать руку или E: персонаж входит в поликлинику. Вход/выход — переход между точками, не непрерывное прохождение через фасад.
3. Дойти до шкафа в кабинете справа, открыть обыск, выбрать рацию и нажать «Забрать».
4. По желанию обыскать рюкзак в зале ожидания и ящик у скорой. Полевой рюкзак можно надеть в снаряжении, ёмкость увеличится с 18 до 30 кг.
5. Выйти через главный вход, отойти вниз к воротам и нажать «Вернуться».

Снаряжение: кнопка рюкзака или I. Расходники восстанавливают параметры. Инструменты, фонарь и одежда — предметы без дополнительных активных механик в этой версии. Бумажная модель персонажа иллюстрирует исходный комплект; смена рюкзака пока не меняет рисунок героя.

## Графика

- `dist/assets/clinic-v2.webp`: отдельный подробный фон поликлиники без HUD/персонажей, подготовленный встроенной генерацией изображений по одобренному концепту. Фон пока единая картинка с навигационными зонами, не тайловый расширяемый мир. Весь интерьер открыт; динамического скрытия крыши нет.
- `dist/assets/hero/`: 12 спрайтов с прозрачностью (четыре направления, три позы), извлечены из созданного листа и выровнены по ногам.
- `dist/assets/items/`: 12 отдельных иконок с прозрачностью из созданного атласа.
- `dist/assets/paperdoll-v2.webp`: тот же персонаж крупно, из первого кадра спрайтов.
- `dist/assets/menu-v2.webp`: фон меню из одобренного изображения убежища.

Графика подготовлена встроенной генерацией изображений; Pillow применён для разделения атласов, выравнивания и сжатия. Брифы: холодная серая Россия, подробный пиксель-арт; камера и масштаб по Mini DAYZ, экипировка с ориентиром на Innawoods, оригинальные рисунки и интерфейс, тёмный металл и олива, без бежевых подложек. Генерация фона: убрать интерфейс и всех персонажей из концепта поликлиники; спрайты: сетка 3×4, стоя/два шага для юга/запада/востока/севера; иконки: сетка 4×3 с рюкзаком, бинтом, водой, консервами, фонарём, рацией, пассатижами, скотчем, курткой, разгрузкой, ботинками, аккумулятором.

## Сохранение и настройки

`localStorage`: `dead-signal-v2`, отдельно от сохранения старого прототипа. Сохраняются положение, предметы, содержимое контейнеров и завершение задания. Облачной синхронизации и защиты от изменения клиентских данных нет. «Новая игра» заменяет сохранение v2 после подтверждения. Настройки: звук, дождь, честный счётчик FPS и три масштаба камеры. Дождь и шаги синтезированы через Web Audio.

## Проверка

`node checks/engine.test.mjs`: навигационный поиск от старта до каждого контейнера; стены, нормализация диагонали, вход/выход, получение предметов без дублирования, расходники, экипировка, валидация сохранения, завершение цели.

`node checks/ui.test.mjs`: имитация DOM/Canvas, загрузка ресурсов, меню, обыск, перенос, просмотр и использование предмета, завершение, сохранение; вызовы рендера при портретном и альбомном размерах.

Визуальная проверка в реальном браузере и измерение FPS на Android не выполнены: разрешённый браузерный инструмент недоступен. Целевые 30 FPS ещё не подтверждены.
